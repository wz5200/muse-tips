## 怎么用这份合集

- 刚开始用 Muse：先看 `01-basic-use.md`，把每天早上那三件事设好。
- 想让它更像自己人：看 `02-personality-memory.md`，先分清 Soul、Identity、Memory 各管什么。
- 房间和空间越建越多：看 `03-side-chats-spaces.md`，只归档、不乱删。
- 想玩声音和视频配音：看 `04-voice.md`。
- 想直接拿现成的应用：看 `05-in-muse-apps.md`，去 Muse应用空间里用。
- 想让手机、电脑都连上：看 `06-phone-pc.md`。
- 每个月抽一次空：按 `07-maintenance.md` 做一次大扫除和备份。
